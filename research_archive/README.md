# Original payment-study analysis and aggregate outputs

GIPE Group 8: Aayushika Bhardwaj, Shreya Bhardwaj, Adhya Pande, Kunal Sachdeva, Bipasha and Arinjai Das.

This archive preserves three recovered original Python analysis scripts and eight historical aggregate result tables. These files differ from the runnable synthetic demonstration in the project root. No participant-level responses, identifiers or individual model predictions are included.

## Contents

- `original_analysis/digital_choice_analysis.py`: recovered main analysis.
- `original_analysis/robustness_checks_block.py`: original robustness extension.
- `original_analysis/Advanced_ML_Robustness_Extension.py`: original specification, predictive and treatment-effect extensions.
- `historical_aggregate_results/`: specification-level estimates, aggregate method summaries, out-of-fold score summaries and aggregate feature importance.

The three scripts parse successfully. Their original empirical pipeline has not been rerun for this release because the participant-level source input is intentionally absent. File paths and execution assumptions remain as in the recovered scripts. Do not supply the synthetic demonstration CSV to the original scripts and describe the result as a reproduction of the study.

The archived aggregate estimates are historical study outputs. Their presence does not independently establish random allocation, causal identification, valid overlap or out-of-sample generalisation. The named causal-estimation procedures rely on assumptions documented in the underlying research and code.

For a working example that requires no private records, use the synthetic implementation and tests in the project root. Contributions remain collaborative, with ChatGPT assistance in the analytical and publication workflow.
