# Contributing

Use a separate environment and follow REPRODUCIBILITY.md. Run the project's existing checks and complete example before proposing numerical changes. State the data definition, units, sample period and expected effect of a change. Keep synthetic examples labelled and preserve contributor credit.

Do not submit credentials, participant-level study records or institutional microdata. Original research archives retain their own provenance and reproduction limits. Changes to model selection, calibration or evaluation should explain how chronology and benchmark comparability are preserved.
